# Student Feedback Web Application

## Project Description
A simple web-based Student Feedback Application developed using HTML, CSS and JavaScript.

Students can enter:
- Name
- Course
- Feedback

After submission, the feedback is displayed on the webpage.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Actions
- GitHub Pages

## CI/CD
GitHub Actions is used to automatically check the project files whenever changes are pushed to the main branch.

## Deployment
The application is deployed using GitHub Pages.

## Features
- Student feedback form
- Name and course input
- Feedback submission
- Submitted feedback display
- Automated CI/CD workflow
- Live deployment
